# Interface languages

The header supports Korean and English. The browser language determines the first visit; an explicit choice is saved under `civilization-chess-locale`. Switching does not remount the app or change match, draft, replay, or network data.

- `src/i18n.ts`: locale store, render-only translation, and complete-message interpolation.
- `src/locales/en.json`: Korean source phrases mapped to English. Keep numbered placeholders identical to the source.
- `src/LanguageSwitch.tsx`: accessible, persistent language selector.
- UI components call `translateUi()` for rendered text and human-readable accessibility attributes. Do not translate IDs, input values, action payloads, or game-rule comparisons.
- Civilization search accepts Korean names and English names/countries in either language.

When adding UI copy, add its English entry and pass the rendered value through `translateUi()`. For interpolated messages, add a full-message entry with `{0}`, `{1}`, etc. Avoid adjacent placeholders; prefer an explicit complete phrase. Do not translate the game engine's stored data.

Validation: `pnpm test` includes dynamic labels, skill descriptions, tutorial captions, and bilingual search. `pnpm build` checks all render call sites.
