# 그리스 액티브 벡터 1차 제작

2026-10-20 완료. SKILL_ART_STANDARD.md의 고대비 단색 면/투명 여백 기준을 적용한 직접 작성 SVG. 이미지 생성 도구나 사진 자동 추적은 사용하지 않았다. 특정 작품의 구도를 복제하지 않은 창작 도안이다.

- 제우스: 오른쪽을 보는 3/4 흉상, 번개를 쥔 손, 사선 구도.
- 포세이돈: 왼쪽 옆얼굴, 삼지창, 흐르는 머리와 아래쪽 파도.
- 하데스: 정면 얼굴, 낮은 머리띠 형태의 왕관, 아래쪽 사슬. 사슬과 구체적 장식은 게임의 죽음 봉인 효과를 위한 창작이며 고대 도상 그대로라고 주장하지 않는다.

지물 근거: 메트로폴리탄 박물관의 Zeus or Poseidon 설명은 성숙한 수염 얼굴과 제우스의 번개/포세이돈의 삼지창을 구분한다.
https://www.metmuseum.org/art/collection/search/251078
월터스 박물관 신들의 행렬에서도 포세이돈의 삼지창, 제우스의 번개와 지팡이가 식별 속성이다.
https://art.thewalters.org/object/23.40/

512×512 viewBox, currentColor 채움, evenodd 여백. 스크립트·외부 이미지·래스터 임베드 없음. 게임에서 GreekSkillIcon이 외부 SVG의 art 그룹을 use로 참조하여 문명별 기존 색을 상속한다. 패시브와 기물 그림은 유지했다. 이전 액티브의 미사용 코드 제거.

검증: pnpm build 통과. 브라우저에서 밝은 배경/어두운 배경 비교 시트와 실제 문명 상세 3×3 스킬 카드의 세 그림 렌더링 확인. review.html에 48/64/96px 비교판 보존. 사용자 최종 미술 승인 전 1차 시안.
