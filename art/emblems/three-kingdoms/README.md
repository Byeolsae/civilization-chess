# 고구려 · 백제 · 신라 로고

2026-10-19 사용자 첨부 이미지를 순서대로 적용했다. 역사적 국기 인증이 아니라 사용자 지정 도안의 재현이다.

- references/: 제공 원본.
- *-flag.svg: 원본 화면 비율, 배경색, 문양 배치 유지.
- public/civilizations/{goguryeo,baekje,silla}{,-w,-b}.svg: 게임 UI용 원형 배경, 문양 종횡비 유지. 진영에 따라 원본 색을 바꾸지 않는다.
- paths.json: 추출 경로와 색상.
- preview.png: 위는 깃발, 아래는 게임 로고. 왼쪽부터 고구려·백제·신라.

재생성: node scripts/trace-three-kingdom-emblems.mjs [sharp 모듈 경로]

검정/흰색 픽셀 경계를 추출해 미세 단순화했다. 작은 압축 잡음은 제거하며 저해상도/JPEG 원본에 없는 세부를 새로 창작하지 않는다. 따라서 픽셀 단위 복제는 아니며 원본 윤곽과 내부 빈 공간을 보존하는 벡터 변환이다. 일반 아이콘 생성기와 별도로 관리한다.
