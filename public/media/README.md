# 문명 미디어

2026-10-13 사용자 요청으로 모든 문명 배경 이미지를 제거했다. 현재 `civilizationMedia`의 배경은 모두 null이다. 기본 UI 바탕을 표시하며 배경 보기·전환은 사용할 수 없다.

6개 문명의 BGM과 크레딧·음량 정규화·루프 처리는 유지한다. 음악과 배경 설정은 별개이며 배경 삭제로 음원을 지우지 않는다.

앞으로 배경을 제작할 때는 먼저 [배경 제작 기준](../../BACKGROUND_STANDARD.md)을 따른다. 이미지가 완성되어 검수를 통과하면 `src/civilizationMedia.ts`에 연결한다. 공개 파일이므로 참조 자료의 사진을 무단으로 복사해 배포하지 않는다.
